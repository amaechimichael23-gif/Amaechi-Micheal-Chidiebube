## Practical Title
Variables, Data Types, Expressions and Input/Output

## Objective
To practise declaring and using Java variables, selecting suitable data types, performing arithmetic operations, accepting keyboard input with `Scanner`, and displaying formatted results.

## Tools Used
- Java Development Kit (JDK)
- Visual Studio Code
- Git
- GitHub Desktop
- GitHub

## Programs
1. `week03/SimpleCalculator.java` — accepts two numbers and displays their sum, difference, product and quotient. It checks for division by zero.
2. `week03/AverageCalculator.java` — accepts a student's name and three scores, then calculates the total and average.
3. `week03/ItemCost.java` — accepts an item name, quantity and unit price, then calculates the total cost.

## How to Compile and Run
Open a terminal in the `week03` directory.

**Simple calculator**
```bash
javac SimpleCalculator.java
java SimpleCalculator
```

**Student average calculator**
```bash
javac AverageCalculator.java
java AverageCalculator
```

**Item cost calculator**
```bash
javac ItemCost.java
java ItemCost
```

## Testing
Test each program with different valid inputs. For `SimpleCalculator.java`, also enter zero as the second number to confirm that the program displays the division-by-zero message.

## Learning Outcome
The practical demonstrates how Java programs receive input, store values in variables, process data using arithmetic expressions and display results.
